# BASKET SOUND DJ

Première maquette web installable (PWA) de l'application de régie sonore de basket.

## Contenu de cette version

- Interface pensée pour le mode paysage.
- Cinq catégories : Attaque, Défense, Ambiance, Match et Mes sons.
- 52 boutons de démonstration répartis dans les quatre premières catégories.
- Volume général, bouton STOP ALL et thème clair/sombre.
- Manifest PWA et service worker pour préparer l'installation et le cache hors ligne.

## Important

Les sons de cette première maquette sont des tonalités générées par le navigateur. Ce ne sont pas encore les vrais effets sonores, musiques ou annonces. Les fichiers audio définitifs devront être ajoutés avec les droits nécessaires.

## Lancer le projet

Publier les fichiers sur un hébergement HTTPS (par exemple GitHub Pages). Sur iPhone/iPad, ouvrir le site dans Safari puis utiliser **Partager > Sur l'écran d'accueil**.

Le verrouillage du téléphone ou la fermeture du navigateur peut interrompre la lecture audio. Cette maquette ne fournit pas encore de compte, de synchronisation cloud, d'import MP3 ni d'abonnement Premium.
